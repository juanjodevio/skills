# Technology Template

Use the Project's established structure when it is clear. For a new or sparse
Technology Steering artifact, adapt this shape:

```markdown
# Project Technology

## Technical Summary

## Tools And Platforms

## Commands

## Integrations And Services

## Constraints And Conventions

## Assumptions

## Unknowns

## Last Reviewed
YYYY-MM-DD by <reviewer or source>
```

Omit empty optional sections when they add no information. Commands should be
exact when known; mark inferred commands as unverified. `Assumptions`,
`Unknowns`, and `Last Reviewed` should make meaningful uncertainty and freshness
visible, not imply certainty that has not been established.
