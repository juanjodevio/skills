# Project Steering Skills

Language for the skill suite that keeps durable repository guidance accurate and turns settled intent into executable work.

## Language

**Project steering**:
The practice of maintaining durable project truth and carrying settled intent into planned work.
_Avoid_: Product steering, repo memory, project documentation

**Project**:
The body of work represented by a repository, whether it is a software product, data platform, marketing program, or mixed initiative.
_Avoid_: Product, repository

**Steering artifact**:
A repository document that owns one kind of durable project truth, such as project intent, technical direction, design direction, delivery sequence, or repository structure.
_Avoid_: Steering doc, memory file

**Steering workflow**:
The shared process that reads evidence, resolves important uncertainty, updates a steering artifact, checks consistency, and identifies related work.
_Avoid_: Doc-writing flow, common process

**Domain model**:
The shared understanding of a project's concepts, their precise meanings, and their relationships.
_Avoid_: Glossary, terminology list

**Work lifecycle**:
The default path from unresolved intent through grilling, Specification, Tickets, implementation via `implement-spec`, and retrospective learning.
_Avoid_: Development pipeline, delivery pipeline

**Situational skill**:
A skill invoked when a specific need arises rather than as a required stage of the Work lifecycle. Named Situational skills include `handoff`, `wait-what`, and architecture review; they are not lifecycle stages.
_Avoid_: Optional lifecycle stage

**Ticket**:
The smallest independently verifiable slice of a specification that fits in one fresh agent context.
_Avoid_: Task, step, issue

**Specification**:
One coherent outcome delivered through one integration branch and one final acceptance decision.
_Avoid_: Project, initiative, plan

**Work tracker**:
The configured system that stores specifications, tickets, their roles, blocking relationships, and progress.
_Avoid_: Linear, issue tracker

**Frontier**:
Every unfinished agent ticket whose blocking tickets are complete and which can therefore execute now.
_Avoid_: Queue, backlog
